Date
Days as Columns (wide) is hidden because the time side already uses an hour-range. Only one wide pivot is supported per file.
Each column in the range holds the observation value for one day of the month. The observation value column is derived from this pivot.
Time
Hours as Columns (wide) is hidden because the date side already uses a day-range. Only one wide pivot is supported per file.
Each column in the range holds the observation value for one hour-of-day. The observation value column is derived from this pivot.
