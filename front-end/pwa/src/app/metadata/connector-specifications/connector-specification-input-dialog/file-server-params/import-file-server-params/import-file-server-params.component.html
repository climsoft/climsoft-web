File Source Pattern — the last segment is always a filename glob (* = any characters). Examples: *.csv (.csv files in the root folder), * (every file in the root folder), stationA/*.csv (.csv files directly in stationA), stationA/**/*.csv (.csv files in stationA and every subfolder), **/*.csv (.csv files anywhere under the root folder).
Exclude — optional, comma-separated file names that are never data, dropped from what the pattern matches: e.g. *_info.csv, README*. A file name containing a comma is excluded by writing * in the comma's place.
