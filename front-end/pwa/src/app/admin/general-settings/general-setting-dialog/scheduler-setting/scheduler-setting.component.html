Connector Run Retention
Each connector run records the full state of the file server it points at, so this is counted in runs rather than days. The newest run of every connector is always kept, because it is what the next run compares against to decide which files have changed. Only runs that actually reached the server count towards this.
A run that never connected holds no files, so it is kept by age instead — long enough for a sysadmin to see that a connector has been failing.
